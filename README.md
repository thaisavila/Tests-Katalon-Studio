#🧪 Projeto de Automação de Testes com Katalon Studio

## 📌 Sobre o Projeto
Este repositório contém os casos de teste automatizados desenvolvidos com Katalon Studio para um sistema de Pet Shop. O projeto faz parte de um trabalho acadêmico do curso de Análise e Desenvolvimento de Sistemas e tem como objetivo demonstrar a aplicação de testes automatizados em aplicações web.

## O sistema testado inclui funcionalidades como:
- Cadastro de usuários e login
- Agendamento de serviços (banho, tosa, etc.)
- Consulta de serviços e categorias
- API REST para registro de usuários, pets e agendamentos

Link para repositório do site usado nos testes: https://github.com/thaisavila/Web-Pet-Shop

## 🛠️ Ferramentas Utilizadas
Katalon Studio (versão gratuita/Community)

## ▶️ Como Rodar os Testes
### Pré-requisitos
- Katalon Studio instalado (baixe em https://www.katalon.com/)
- Sistema web pet shop rodando em localhost
- Backend rodando (API FastAPI em http://localhost:8000)

### Passos para Execução
1. Clone o repositório:
bash
git clone

2. Inicie o Katalon Studio

3. Abra o projeto no Katalon Studio
Clique em File > Open Project > Selecione a pasta do projeto clonado

4. Execute os testes:
- Para rodar um caso individual: clique com o botão direito no Test Case > Run
- Para rodar uma suíte completa: clique com o botão direito na Test Suite > Run

5. Visualize os relatórios:
Após a execução, os relatórios são gerados automaticamente na pasta Reports/
Você também pode visualizar no próprio Katalon na aba Reports

## Casos de Teste Implementados
- Foi feito principalmente testes de funcionalidade e teste de aceitação
- O projeto inclui tanto casos de sucesso quanto casos de erro para demonstrar a capacidade do Katalon de identificar falhas
- O projeto inclui tanto casos de o que o sistema deve fazer  casos do que o sistema não deve fazer
